# Постановка задачи

**Проект:** «Хайку» — редактор хайку с подсчётом слогов
**Статус:** реализовано (v1.2.0)
**Стек:** React 18 + Vite 5, чистый JSX (без TypeScript), CSS

## Цель

Дать пользователю возможность набирать классический хайку из трёх строк (5-7-5 слогов) с наглядным контролем количества слогов в каждой строке и быстрым копированием готового стихотворения.

## Функциональные требования

1. **Три строки ввода** с целевым числом слогов 5, 7, 5 (источник истины — `TARGETS` в `src/App.jsx`).
2. **Подсчёт слогов** по количеству гласных: латиница + кириллица (`VOWELS` в `src/App.jsx`). Счётчик выводится слева от каждой строки.
3. **Индикация достижения цели:** счётчик подсвечивается, когда число слогов совпадает с целевым; когда все три строки идеальны — появляется кнопка «Скопировать».
4. **Копирование хайку** в буфер обмена (Clipboard API с фолбэком на `execCommand`).
5. **Навигация с клавиатуры:** Enter — следующая строка, ↑/↓ — переход между строками.
6. **Интерфейс на русском языке** (`lang="ru"`), вся пользовательская текстовая часть — русская.
7. Используй шрифт Sangha

## Дополнение (v1.2.0, реализовано): тёмный фон в японском стиле

10. **Фон:** многослойный тёмный фон в японском стиле — чернильный градиент неба, дымка у горизонта, силуэты гор, полупрозрачный багровый диск «солнца» в верхне-правой части, тонкая звёздная решётка (асаноха) и лёгкое зерно. Фон фиксирован при прокрутке.
11. **Читаемость:** строки ввода, счётчики, панель подсказок и подпись остаются над фоном (z-слой); панель подсказок — полупрозрачная с размытием, её подложка темнее фона.

## Дополнение (v1.1.0, реализовано): окно справа и надпись снизу

8. **Окно справа — справка/подсказки:** панель, закреплённая у правого края экрана (на узких экранах — колонкой под стихотворением). Содержание:
   - правило формы: «классическое хайку — три строки 5-7-5 слогов»;
   - управление: «Enter — следующая строка», «↑/↓ — переход между строками», «когда строки 5-7-5 — появится кнопка „Скопировать"»;
   - смысл подсветки: «розовое число — слогов не по форме, белое — цель достигнута»;
   - стиль панели согласован с интерфейсом: чёрный фон, рамка/панель темнее фона, шрифт Sangha, акценты розовым.
9. **Надпись снизу:** строка «Сайт сделан во славу и с разрешения королевы Рагнейд» постоянно закреплена у нижнего края экрана при любом размере окна, включая мобильные (фиксированная позиция; мелкий кегль, ненавязчивый цвет с тенью для читаемости; не перекрывает строки ввода и панель справа — контент имеет нижний отступ).

## Критерии приёмки

- `npm run build` проходит без ошибок (единственный шаг проверки: тесты/линт отсутствуют).
- Все пункты функциональных требований работают в собранном `dist/`.
- Счётчик слогов корректен для строк на русском и латинице.
- Панель подсказок отображается справа (на узких экранах — под стихотворением); подпись «Сайт сделан во славу и с разрешения королевы Рагнейд» закреплена внизу экрана при любом размере окна, включая мобильные.
